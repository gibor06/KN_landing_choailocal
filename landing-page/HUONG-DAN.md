# CHỢ AI LOCAL - LANDING PAGE

## 🎯 Giới thiệu
Landing page giới thiệu dự án **Chợ AI Local** cho cuộc thi khởi nghiệp đổi mới sáng tạo.

## 🚀 Cách sử dụng

### Cách 1: Mở trực tiếp (Đơn giản nhất)
1. Vào thư mục `landing-page`
2. Click đúp vào file **`index.html`**
3. Trang sẽ tự động mở trên trình duyệt mặc định

### Cách 2: Mở bằng trình duyệt cụ thể
1. Click phải vào file **`index.html`**
2. Chọn "Open with" / "Mở bằng"
3. Chọn trình duyệt bạn muốn (Chrome, Firefox, Edge, Safari)

### Cách 3: Kéo thả
1. Kéo file **`index.html`** vào cửa sổ trình duyệt đang mở

## 📁 Cấu trúc thư mục

## 🐛 Khắc phục sự cố

### Trang không hiển thị đúng?
- Kiểm tra kết nối Internet (để load Bootstrap từ CDN)
- Thử trình duyệt khác
- Xóa cache và reload (Ctrl+F5)

### Icons không hiện?
- Kiểm tra kết nối Internet
- Reload trang (F5)

### Animation không chạy?
- Kiểm tra JavaScript đã enable chưa
- Mở Developer Tools (F12) xem console có lỗi không
