===================================
CHỢ AI LOCAL - LANDING PAGE
===================================

GIỚI THIỆU:
-----------
Đây là landing page giới thiệu dự án "Chợ AI Local" cho cuộc thi khởi nghiệp.
Trang được xây dựng bằng HTML5, CSS3, JavaScript thuần và Bootstrap 5.

CÁCH SỬ DỤNG:
------------
1. Mở file index.html bằng trình duyệt web (Chrome, Firefox, Edge, Safari)
2. Không cần cài đặt thêm gì vì Bootstrap và Bootstrap Icons được load từ CDN
3. Không cần web server, chỉ cần mở file trực tiếp

CẤU TRÚC THỨ MỤC:
----------------
landing-page/
├── index.html          # File HTML chính
├── css/
│   └── style.css       # File CSS tùy chỉnh
├── js/
│   └── main.js         # File JavaScript tùy chỉnh
└── assets/
    └── README.txt      # File này
